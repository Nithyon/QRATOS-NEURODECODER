# Hybrid Q — Frontend

React + TypeScript dashboard for the Hybrid Riemannian-Quantum BCI pipeline.

## Prerequisites
- Node.js 18+

## Run
```bash
npm install
npm run dev
```

The dev server starts on `http://localhost:3000`.

## Key Components
- **Dashboard** — live mission HUD with EEG stream, decoder, and metrics
- **CodeViewer** — embedded backend source viewer
- **EEGVisualizer** — 4-channel EEG chart (C3, C4, Pz, Fz)
- **HumanFigure** — neuromotor SVG with cross-lateral brain mapping
- **MetricsCard** — real-time metric tiles
